### Outline (1–2 pages)

1. **Disclaimer** (encadré) : information publique uniquement — **pas un conseil financier, juridique ou fiscal** ; pas de recommandation d’achat/vente ; snapshot daté.
2. **Ce que c’est** : dépôt ETH → stETH ; rebase ; rôle des oracles Lido (vue docs publiques).
3. **Chiffres du snapshot** (à figer le jour de publication) :
   - APR / yield 7j et 30j (sources : Chartegy / Castle Labs / Lido API)
   - Ordre de grandeur gas L1 pour un stake (GasNow)
4. **Risques** (liste) : smart-contract, oracle, gouvernance/admin, liquidité stETH/ETH, file d’attente validateurs, confusion UI phishing.
5. **Anti-scam checks** : domaines officiels, pas de seed, pas de « wrap » via site miroir.
6. **Sources** (liens cliqués) + « ce qui n’est pas établi ».
7. **Hors scope** : audit code complet, shill, price target.
